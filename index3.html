Aula 1 - Introdução ao HTML

O que eu entendi?

Eu entendi que HTML é utilizado para criar a estrutura de uma página na internet. É através dele que organizamos os textos, títulos, imagens, links e outros elementos que aparecem em um site.

O HTML é como a estrutura de uma casa: ele define onde cada elemento ficará.

Aula 2 - Estrutura e títulos

O que eu entendi?

Aprendi que todo documento HTML possui uma estrutura básica. Temos o cabeçalho, onde ficam informações da página, e o body, onde colocamos o conteúdo que será apresentado ao visitante.

Hierarquia dos títulos

Os títulos são organizados do h1 até o h6. O h1 representa o título principal e os demais ajudam a organizar os assuntos da página.

Aula 3 - Parágrafos e textos

O que eu entendi?

Aprendi que a tag p é utilizada para criar parágrafos. Ela permite organizar o conteúdo em blocos de texto, deixando a leitura mais organizada.

Também entendi que podemos utilizar vários parágrafos dentro de uma mesma página.

Aula 4 - Formatação de textos

O que eu entendi?

Aprendi que existem tags que permitem destacar determinadas partes de um texto.

Strong: destaca um texto com importância.

Italic: deixa o texto em itálico.

Underline: coloca um sublinhado no texto.

Mark: destaca um trecho como marca-texto.

Small: apresenta um texto menor.

Aula 6 - Tags complementares

O que eu entendi?

Existem outras tags que ajudam a complementar e organizar as informações de uma página.

Exemplos que aprendi:

A tag blockquote permite apresentar uma citação:

O sucesso é a soma de pequenos esforços repetidos todos os dias.

A tag del indica um texto removido: Texto antigo

A tag abbr permite apresentar o significado de uma abreviação.

HTML é a linguagem de marcação que estou aprendendo.

A tag sub permite apresentar texto inferior, como H2O.

A tag sup permite apresentar texto superior, como 22.

A tag hr cria uma linha horizontal para separar conteúdos.

A tag font permite alterar características visuais do texto, como sua cor.
